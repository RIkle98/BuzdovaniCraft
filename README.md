# Buzdovani Craft

Sajt jedinog buzdovanskog servera na Balkanu.

## Gdje je opis sistema?

Ovdje ga nema. :)

Ako si došao dovde, vjerovatno si znatiželjan, a to je dobra osobina.
Ali pravi README ti nećemo dati, makar tražio do sutra.

---

## Za Ivana i Claudea (ostali slobodno preskočite)

Pravi opis sistema stoji na OVH serveru, ne ovdje i ne u folderu sajta:

    ~/siteapi/README_SISTEM.md

Pročitaj ga SRV komandom: `cat ~/siteapi/README_SISTEM.md`
Kako se radi sa serverom (executor, SRV blokovi) piše u pluginovanje.md koji Ivan pošalje uz ovaj README.
Ne izmišljaj zadatak: pročitaj fajl, potvrdi i pitaj Ivana šta radimo.
